# Руководство по использованию сервиса YouGile
## 1. Общее описание сервиса
YouGile (Юджайл) — российская облачная система управления проектами и задачами, объединяющая инструменты таск-трекинга, корпоративный мессенджер, CRM и AI-возможности. Продукт разработан компанией ООО «ЮДЖАЙЛ» и внесён в Единый реестр российского программного обеспечения.

Сервис позиционируется как гибкое решение для малого и среднего бизнеса, стартапов и проектных команд. Ключевая особенность YouGile объединение коммуникации и управления задачами в единой среде: каждая задача представляет собой чат, где хранится вся история обсуждений,
документы и правки. Основные преимущества:
- Российское ПО с серверами на территории РФ, что гарантирует стабильность работы независимо от внешних санкций
- Кроссплатформенность: веб-версия, десктопные приложения для Windows, macOS и Linux, мобильные приложения для Android и iOS
- Бесплатный тариф для команд до 10 человек без ограничений по функционалу
## 2. Аппаратное, программное и информационное обеспечение
### 2.1 Аппаратные требования
YouGile не предъявляет высоких требований к аппаратному обеспечению при использовании облачной версии. Для коробочной (локальной) версии требования следующие:
| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
|Оперативная память|2 GB|4 GB|
|Свободное место на диске|5 GB| Зависит от объёма данных|
|Процессор |Любой современный| —|
### 2.2 Программное обеспечение
Облачная версия работает в любом современном браузере без установки дополнительного ПО. Для десктопной версии требуются:
- Windows: Windows 10/11 (64-bit)
- macOS: версии с актуальной поддержкой Apple
- Linux: Ubuntu, Debian, CentOS, RHEL, Fedora
Мобильные приложения требуют iOS 15.0+ или Android (APK доступен для скачивания)
Коробочная версия разворачивается на сервере организации и требует:
- Docker (версия 20.10+) + Docker Compose (версия 2.0+)
- Поддерживаемые ОС: Linux (Ubuntu, Debian, CentOS, RHEL, Fedora), macOS, Windows (с WSL2)
### 2.3 Информационное обеспечение
YouGile хранит все данные в собственном формате на сервере. Для облачной версии данные размещаются на серверах в РФ. Коробочная версия позволяет хранить данные полностью на сервере организации без подключения сторонних баз данных.

Для хранения загружаемых файлов в коробочной версии можно подключить S3-совместимое объектное хранилище (например, Яндекс Облако) через инструменты geeseFS или s3fs-fuse.
## 3. Основной функционал и руководство по использованию
### 3.1 Создание проектов и архитектура пространства
При первом входе в YouGile рекомендуется создать Пространство — это верхнеуровневая единица, соответствующая компании или направлению. Внутри пространства создаются Проекты, каждый из которых содержит доски с задачами.
Алгоритм создания проекта:
1. В главном меню нажмите «+» в разделе «Проекты»
2. Укажите название проекта и добавьте участников
3. Настройте структуру: создайте доски и колонки
Рекомендуемая структура колонок (конвейер задач):
Сырая идея → Проработка (ТЗ) → В работе → Проверка (ОТК) → Завершено

Такая последовательность ведёт сотрудника по процессу: не нужно спрашивать «что дальше?» — достаточно переместить карточку в следующую колонку.
### 3.2 Создание и отслеживание задач
Каждая задача — это карточка на доске. Внутри карточки доступны:
- Описание задачи и критерии выполнения
- Чат для обсуждения — вся коммуникация фиксируется в контексте задачи
- Файлы и вложения
- Исполнитель (один ответственный)
- Дедлайн
- Стикеры (приоритет, тип задачи и т.д.)
Создание задачи: нажмите «+» на доске или в колонке, введите название, назначьте исполнителя и укажите срок.

Отслеживание: в разделе «Мои задачи» собираются все задачи пользователя из разных проектов. Можно включить сортировку по дедлайну, чтобы ближайшие задачи были вверху.

Сводки — это колонки с автоматической фильтрацией задач по заданным условиям (например, «Просроченные задачи», «Задачи на эту неделю»). Сводки настраиваются один раз и автоматически обновляются.
### 3.3 Создание документации средствами продукта
YouGile позволяет создавать и хранить документацию непосредственно в задачах и проектах:
- Вложения: к задаче можно прикрепить файлы (документы, таблицы, изображения)
- Описания задач: структурированное описание с чек-листами
- Комментарии и чаты: документация в виде обсуждений с возможностью закрепления важных сообщений
- Прикрепление фото и видео: прямо из мобильного приложения можно сделать фото или записать видео и прикрепить к задаче
### 3.4 Управление ролями участников
YouGile предоставляет гибкую систему прав доступа. Готовые роли:
|Роль| Права|
|----|------|
|Управляющий| Полный доступ к проекту и настройкам|
|Сотрудник| Редактирует все задачи, но не управляет проектом|
|Менеджер CRM|Работает только со своими сделками|
|Наблюдатель|Видит всё, но ничего не редактирует|

Для тонкой настройки можно создать пользовательскую роль — доступно 54 пункта настроек под любой сценарий.

Ключевой принцип: исполнитель имеет право на выполнение, руководитель — на приёмку конечного продукта. Это исключает закрытие задач без проверки.
### 3.5 Методологии управления: Agile, Kanban, диаграмма Ганта
YouGile поддерживает три взаимодополняющих подхода:
- Agile — мышление и планирование будущего. Крупные цели делятся на спринты
- Kanban — визуализация текущего процесса. Правило: не более двухактивных задач на одного исполнителя
- Диаграмма Ганта — визуализация связей и дедлайнов. Показывает, как срыв одного срока влияет на всю цепочку
Работа с диаграммой Ганта: откройте доску проекта, переключитесь в режим диаграммы Ганта, добавьте этапы и расставьте сроки от финальной даты (обратное планирование).
### 3.6 Контроль дедлайнов
Инструменты контроля:
- Отчёты: показывают задачи без дедлайна или просроченные
- Обязательный дедлайн: в настройках стикера «Дедлайн» включите опцию «Требовать указать значение»
- Шаблоны задач: для повторяющихся задач срок подставляется автоматически (например, «+3 дня»)
- Уведомления: о назначении задач, дедлайнах, упоминаниях
### 3.7 Коммуникация: встроенный мессенджер
YouGile включает полноценный мессенджер:
- Чат задачи — обсуждение в контексте
- Голосовые сообщения с автоматической транскрипцией в текст
- Реакции на сообщения
- Прикрепление файлов, фото, видео
- Упоминания через «@» — гарантируют, что человек увидит обращение
### 3.8 AI-возможности
В YouGile интегрирован AI-ассистент, работающий на внутреннем сервере компании — все данные остаются внутри организации. Ассистент умеет:
- Запускать новый проект: предложит варианты процесса на доске, создаст доску, добавит этапы и подберёт формат (Канбан, Гант или календарь)
- Собирать данные по сложным запросам: например, «Выведи задачи, в которые за последние недели было больше всего обсуждений в негативном ключе»
- Разбираться со сроками: найдёт карточки по тегам, статусам и комментариям, обновит дедлайны и перенесёт задачи между колонками
- Показывать узкие места: где копятся задачи, предложит лимиты и соберёт сводку по загрузке команды
- Создавать шаблоны по прошлому проекту: повторит структуру, этапы и оформление
Управление голосом: зажмите Alt (Option на macOS), кликните на задачу и скажите, например: «Поставь дедлайн сегодня на 19:00» — система сама обновит задачу
### 3.9 Интеграции
YouGile предоставляет открытый REST API, позволяющий связать систему с 1С, CRM, почтой, Telegram (через webhooks) и другими сервисами. API позволяет управлять пользователями, ключами доступа, задачами и проектами.
## 4. Лайфхаки и неочевидные сценарии использования
### 4.1 Автоматизация через встроенный конфигуратор
YouGile позволяет писать скрипты автоматизации на JavaScript прямо в интерфейсе. Это открывает множество неочевидных возможностей:
Создание нескольких задач из одной строки. Вставьте в поле создания задачи текст с переносами строк — система автоматически разобьёт его на отдельные задачи. Это удобно для быстрого ввода списка дел.

Назначение себя исполнителем через Shift. Зажмите Shift и кликните на карточку задачи — вы автоматически станете исполнителем и подпишетесь на чат задачи. Не нужно открывать карточку и вручную выбирать себя.

Прочитать все чаты одним сочетанием. Нажмите Ctrl + Shift + Backspace — скрипт пройдёт по всем задачам, где вы подписаны на чат, и
отметит их как прочитанные.

Обязательный комментарий при перемещении. Можно настроить скрипт так, чтобы при перемещении задачи в определённую колонку (например,
«Готово») система требовала ввести комментарий — что именно было сделано.

Счётчик задач в колонке. Скрипт может отображать количество задач в каждой колонке прямо в интерфейсе — удобно для контроля перегрузки.
Лимит задач в колонке. Расширение позволяет установить лимит: если задач больше нормы, лишняя подсветится красным. Это визуальный сигнал о заторе в процессе.
### 4.2 Интеграция с Telegram для приёма заявок
YouGile можно использовать как helpdesk или систему приёма заявок через Telegram-бота. Настройка не требует программирования:
1. Создайте бота через @BotFather в Telegram.
2. В YouGile (раздел «Моя компания» → «Расширения») подключите
интеграцию с Telegram.
3. Укажите токен бота и выберите колонку, в которой будут создаваться
задачи из сообщений.
Как это работает: клиент пишет сообщение боту → задача автоматически создаётся в YouGile. Сотрудник отвечает через интерфейс YouGile — клиент получает ответ в Telegram. Бесплатный тариф позволяет вести диалог с 500 клиентами в месяц. Создание задач из Telegram: напишите боту /task Название задачи — задача появится в YouGile.
### 4.3 YouGile как персональный таск-менеджер
Сервис можно использовать не только для командной, но и для личной работы. Создайте пространство «Личное», доски «Работа», «Дом», «Обучение». Используйте сводки для автоматической фильтрации:
- «Задачи на сегодня»
- «Просроченные»
- «Ждут ответа»
Правило одного ответственного работает и в личных задачах: одна карточка — один результат. Это дисциплинирует.
### 4.4 Использование стикеров для маркировки
Стикеры в YouGile — это не просто теги. Их можно использовать как мини-базу данных:
- Стикер «Клиент» с текстовым значением — фиксируйте названиекомпании
- Стикер «Бюджет» с числовым значением — сумма сделки
- Стикер «Источник» — откуда пришла заявка
Скрипт может автоматически считывать первые цифры из описания задачи и крепить их числовым стикером — например, для извлечения номера заказа.
### 4.5 Интеграция с AI-агентами через MCP
Для технически продвинутых пользователей существует YouGile MCP (Model Context Protocol) — сервер, который позволяет AI-агентам (Claude
Desktop, Cursor и др.) напрямую управлять задачами в YouGile.
Что это даёт: вы можете попросить AI-ассистента:
- «Покажи все просроченные задачи по проекту X»
- «Создай задачу в колонке "Разработка" с дедлайном на пятницу»
- «Прочитай комментарии к задаче и summarise обсуждение»
- «Перемести все задачи с стикером "Срочно" в колонку "В работе"»
AI-агент видит структуру проектов, досок, колонок и задач, может создавать, перемещать, комментировать и архивировать задачи. Это открывает сценарии «управления проектами через чат с AI».
### 4.6 Автоматизация через Albato и n8n
Для интеграции YouGile с внешними сервисами (Google Sheets, CRM, почта) можно использовать no-code платформы автоматизации:
- Albato: готовая интеграция Telegram Bot ↔ YouGile. Можно настроить сценарии: «Новое сообщение в Telegram → Создать задачу в YouGile», «Задача обновлена → Отправить уведомление в Telegram»
- n8n: примеры использования включают создание задач через HTTP Request с AI-классификацией по отделам. Бот в Telegram принимает сообщение, AI определяет, к какому проекту оно относится, и создаёт задачу в нужной колонке
### 4.7 Неочевидные фишки мобильного приложения
- Обязательные стикеры: если в веб-версии настроены обязательные стикеры для проекта, в мобильном приложении задача не создастся, пока вы их не заполните
- Дублирование задач: повторяющиеся задачи (например, еженедельное совещание) можно копировать в один клик
- Поиск по ID: ищите задачи по любому формату — MOB-123, MOB 123 или MOB123
- Расшифровка голосовых в push: текст голосового сообщения виден прямо в уведомлении, без открытия чата
- Быстрый чат проекта: при создании доски можно одним нажатием добавить всех участников в общий чат
### 4.8 Сценарий YouGile как CRM
Благодаря интеграции с Telegram и расширению CRM (менеджер сделок), YouGile можно использовать как лёгкую CRM для отдела продаж:
- Заявки приходят через Telegram-бота
- Создаётся сделка в CRM YouGile
- Менеджер ведёт клиента по этапам: «Новый лид» → «Квалификация» → «Предложение» → «Сделка»
- Все коммуникации фиксируются в чате задачи
Это решение для малого бизнеса, которому не нужна полноценная CRM, но важно не терять заявки.
