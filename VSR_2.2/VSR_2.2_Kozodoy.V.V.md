# Аналитическая подборка материалов по языку программирования Julia

## Введение

Julia — это высокоуровневый динамический язык программирования, созданный для научных и численных вычислений. Его ключевое преимущество заключается в сочетании простоты синтаксиса, характерной для Python, со скоростью выполнения, сопоставимой с C и Fortran, что достигается благодаря JIT-компиляции (Just-In-Time compilation). Язык был разработан в MIT и впервые выпущен в 2012 году, а на сегодняшний день активно используется в таких областях, как машинное обучение, вычислительная биология, физика, финансы и инженерия.

Особенностью Julia является множественная диспетчеризация (multiple dispatch) — механизм, при котором выбор вызываемого метода функции зависит от типов всех аргументов, а не только первого. Это позволяет писать выразительный и одновременно эффективный код без потери производительности. Julia также поддерживает метапрограммирование, работу с Unicode-символами (например, `\alpha` + Tab преобразуется в `α`), и имеет развитую экосистему пакетов, управляемую через встроенный менеджер `Pkg`.

Данная подборка структурирована следующим образом: сначала представлены аннотированные ресурсы для изучения языка, затем — примеры решения задач различной сложности с подробными пояснениями. Все примеры сопровождаются выдержками кода с комментариями. Подборка ориентирована на русскоязычную аудиторию, однако ряд ключевых ресурсов доступен только на английском языке, что отмечено в аннотациях.

## Раздел 2. Примеры решения задач на Julia

### Задача 1. Сумма чисел, кратных 3 или 5 (Project Euler, задача 1)

Условие: Найти сумму всех натуральных чисел меньше 1000, которые кратны 3 или 5.

Код:

```julia

# Инициализируем переменную-аккумулятор
s = 0

# Проходим по всем числам от 1 до 999
for i in 1:999
    # Проверяем кратность 3 или 5
    if i % 3 == 0 || i % 5 == 0
        s += i  # Добавляем число к сумме
    end
end

println("Ответ: $s")

```
Альтернативное решение:

```julia

# Генератор списка с фильтрацией и функцией sum
result = sum([i for i in 1:999 if i % 3 == 0 || i % 5 == 0])
println("Ответ: $result")

```

Пояснение: в Julia оператор % возвращает остаток от деления. Условие `i % 3 == 0 || i % 5 == 0` истинно, когда число делится на 3 или на 5 без остатка. Первое решение использует явный цикл `for` и аккумулятор — это классический императивный подход, понятный программистам с опытом в C или Python. Второе решение использует генератор списка (list comprehension) и встроенную функцию `sum`, что короче и часто эффективнее. Оба подхода дают правильный ответ: 233168 

### Задача 2. Нахождение наибольшей последовательности простых чисел, порождаемых квадратичным полиномом (Project Euler, задача 27)

Условие: Рассмотрим квадратичный полином вида $n^2+an+b$, где $|a|<1000$ и $|b|<=1000$. Найти произведение коэффициентов `a` и `b`, для которых полином пораждает максимальное количество просстых чисел для последовательных значений `n`, начиная с $n=0$

Код:

```julia

# Функция проверки простоты числа
function isPrime(num)
    num < 2 && return false
    # Проверяем делители до квадратного корня из num
    for i in 2:trunc(Int, √num)
        if num % i == 0
            return false
        end
    end
    return true
end

# Квадратичная функция
function quadratic(n, a, b)
    return n^2 + a*n + b
end

# Подсчёт длины последовательности простых чисел
function consecutivePrimes(a, b)
    count = 0
    tryNum = 0
    while true
        currResult = quadratic(tryNum, a, b)
        # Если число не простое — прерываем последовательность
        isPrime(currResult) && (return count)
        count += 1
        tryNum += 1
    end
end

# Перебор всех возможных a и b
function longestConsecutivePrimes(modA::Int64, modB::Int64)
    longest = (0, 0, 0)  # (длина, a, b)
    for a in -modA:modA, b in -modB:modB
        consecutive = consecutivePrimes(a, b)
        # Обновляем максимум, если нашли более длинную последовательность
        longest[1] < consecutive && (longest = (consecutive, a, b))
    end
    return longest
end

# Запуск с замером времени
A, B = 999, 1000
@time size, a, b = longestConsecutivePrimes(A, B)
println("Длина: $size, a: $a, b: $b")
println("a*b = $(a*b)")

```
Пояснение: Задача требует перебора примерно двух миллионов комбинаций `a` и `b`. Ключевой момент оптимизации — аннотация типов параметров функции longestConsecutivePrimes(modA::Int64, modB::Int64). Без аннотации Julia не может вывести типы аргументов на этапе компиляции, что приводит к динамической диспетчеризации и множеству аллокаций памяти. С аннотацией типов время выполнения сокращается примерно вдвое, а количество аллокаций падает с 36 тысяч до одной . Функция isPrime использует проверку делителей только до $\sqrt{num}$, что даёт существенное ускорение по сравнению с проверкой всех чисел до `num`. Правильный ответ $a=-61, b=971$, произведение $-59231$

### Задача 3. Решение судоку методом возврата (backtracking)

Условие: Реализовать решатель судоку 9×9, который принимает частично заполненную матрицу (0 обозначает пустую ячейку) и возвращает решённую доску.

Код :

```julia

module SudokuSolver

export solve_sudoku, print_board

# Функция поиска пустой ячейки
function find_empty(board::Matrix{Int})
    for i in 1:9, j in 1:9
        if board[i, j] == 0
            return (i, j)
        end
    end
    return nothing
end

# Проверка корректности хода
function is_valid(board::Matrix{Int}, num::Int, pos::Tuple{Int, Int})
    row, col = pos
    
    # Проверка строки
    for j in 1:9
        if board[row, j] == num
            return false
        end
    end
    
    # Проверка столбца
    for i in 1:9
        if board[i, col] == num
            return false
        end
    end
    
    # Проверка квадрата 3×3
    box_start_row = 3 * div(row - 1, 3) + 1
    box_start_col = 3 * div(col - 1, 3) + 1
    for i in 0:2, j in 0:2
        if board[box_start_row + i, box_start_col + j] == num
            return false
        end
    end
    
    return true
end

# Основная рекурсивная функция
function solve!(board::Matrix{Int})
    find = find_empty(board)
    
    # Базовый случай: пустых ячеек нет — судоку решено
    if find === nothing
        return true
    else
        row, col = find
    end
    
    # Пробуем подставить числа от 1 до 9
    for num in 1:9
        if is_valid(board, num, (row, col))
            board[row, col] = num  # Ставим число
            
            # Рекурсивно решаем оставшуюся часть
            if solve!(board)
                return true
            end
            
            # Откат: предыдущий ход был неверным
            board[row, col] = 0
        end
    end
    
    return false
end

# Функция-обёртка для пользователя
function solve_sudoku(board::Matrix{Int})
    println("Начальная доска:")
    print_board(board)
    
    board_copy = copy(board)
    if solve!(board_copy)
        println("\nСудоку решено!")
        print_board(board_copy)
    else
        println("Решения нет.")
    end
end

function print_board(board::Matrix{Int})
    for i in 1:9
        println(join(board[i, :], " "))
    end
end

end # конец модуля

```
Пояснение: Алгоритм использует метод возврата (backtracking): на каждом шаге находится первая пустая ячейка, в неё поочерёдно подставляются числа от 1 до 9, и для каждого допустимого числа рекурсивно решается оставшаяся часть. Если решение не найдено, происходит откат — ячейка снова становится пустой. Функция `is_valid` проверяет три условия: отсутствие дубликата в строке, столбце и квадрате 3×3. Вычисление начальных координат квадрата через `div(row - 1, 3) * 3 + 1` — стандартный приём для определения принадлежности ячейки к блоку. Использование модуля (`module SudokuSolver`) демонстрирует организацию кода в Julia.

### Задача 4. Наибольшее произведение-палиндром (Project Euler, задача 4)

Условие: Палиндромное число читается одинаково в обоих направлениях. Наибольшее палиндромное число, полученное произведением двух двузначных чисел, равно 9009 = 91 × 99. Найдите наибольшее палиндромное число, полученное произведением двух трёхзначных чисел.

Код:

```julia

# Функция проверки, является ли число палиндромом
function is_palindrome(n::Int)
    s = string(n)          # Преобразуем число в строку
    return s == reverse(s) # Сравниваем строку с перевёрнутой версией
end

# Функция поиска наибольшего палиндрома-произведения
function largest_palindrome_product(digits::Int)
    lower = 10^(digits - 1)  # Минимальное число с заданным количеством цифр
    upper = 10^digits - 1    # Максимальное число с заданным количеством цифр
    max_palindrome = 0
    
    # Перебираем пары множителей
    for i in upper:-1:lower
        for j in upper:-1:lower
            product = i * j
            # Оптимизация: если произведение меньше текущего максимума, прерываем внутренний цикл
            product <= max_palindrome && break
            if is_palindrome(product)
                max_palindrome = product
            end
        end
    end
    return max_palindrome
end

# Решение задачи
result = largest_palindrome_product(3)
println("Наибольший палиндром: $result")

```
Пояснение: функция `is_palindrome` использует встроенную функцию `reverse` для строк — идиоматичный приём в Julia. Основная функция `largest_palindrome_product` перебирает множители от максимального к минимальному и использует ранний выход `break`, если текущее произведение уже меньше найденного максимума. Это сокращает количество итераций примерно в два раза. Ответ: 906609 = 913 × 993.

### Задача 5. Разница между квадратом суммы и суммой квадратов (Project Euler, задача 6)

Условие: квадрат суммы первых десяти натуральных чисел равен $(1+2+3...+10)^2=55^2=3025$. Сумма квадратов первых десяти натуральных чисел равна $1^2 + 2^2 + ... + 10^2 = 385$. Разница между квадратом суммы и суммой квадратов для первых десяти чисел составляет $3025-385=2640$. Найдите разницу для первых ста натуральных чисел.

Код (прямолинейное решение):

```julia

# Функция для вычисления суммы квадратов чисел от 1 до n
function sum_of_squares(n::Int)
    total = 0
    for i in 1:n
        total += i^2
    end
    return total
end

# Функция для вычисления квадрата суммы чисел от 1 до n
function square_of_sum(n::Int)
    total = 0
    for i in 1:n
        total += i
    end
    return total^2
end

# Разница между квадратом суммы и суммой квадратов
function difference(n::Int)
    return square_of_sum(n) - sum_of_squares(n)
end

# Решение для n = 100
result = difference(100)
println("Разница: $result")

```
Код (оптимизированное решение):

```julia
# Сумма первых n натуральных чисел: n(n+1)/2
# Квадрат суммы: (n(n+1)/2)^2
# Сумма квадратов первых n чисел: n(n+1)(2n+1)/6

function difference_optimized(n::Int)
    sum_n = n * (n + 1) ÷ 2          # Сумма 1..n
    square_of_sum = sum_n^2          # Квадрат суммы
    sum_of_squares = n * (n + 1) * (2n + 1) ÷ 6  # Сумма квадратов
    return square_of_sum - sum_of_squares
end

result = difference_optimized(100)
println("Разница: $result")

```
Пояснение: Первое решение использует два цикла for: один для суммы квадратов, второй — для квадрата суммы. Это наглядно и легко читается, но выполняется за $O(n)$ операций. Второе решение применяет известные формулы: сумма первых $n$ натуральных чисел равна $\frac{n(n+1)}{2}$, а сумма их квадратов $\frac{n(n+1)(2n+1)}{6}$. Это дает решение за $O(1)$ - константное время, независимо от $n$
Оператор `÷` в Julia выполняет целочисленное деление, что важно для сохранения типа `Int` и предотвращения появления чисел с плавающей точкой. Оба решения дают правильный ответ: 25164150.
